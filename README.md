## Project Overview

This project focuses on analyzing the Netflix Movies and TV Shows dataset using Python. It includes data loading, data cleaning, exploratory data analysis (EDA), statistical analysis, and data visualization to identify meaningful patterns and insights.

## Dataset Information

- **Dataset:** Netflix Movies and TV Shows
- **Source:** Kaggle
- **Original Dataset Link:** https://www.kaggle.com/datasets/shivamb/netflix-shows
- **Total Records:** 8,807
- **Total Columns:** 12

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Tasks

### 1. Data Loading and Understanding

- Imported the required Python libraries.
- Loaded the Netflix dataset.
- Examined the dataset structure, columns, and data types.
- Identified missing values.

### 2. Data Cleaning

- Identified and handled missing values.
- Checked and verified duplicate records.
- Corrected misplaced duration values in the rating column.
- Converted the `date_added` column into datetime format.
- Prepared the cleaned dataset for analysis.

### 3. Exploratory Data Analysis (EDA)

- Analyzed Movies and TV Shows distribution.
- Explored release years and content ratings.
- Analyzed country and genre distributions.
- Examined movie durations and TV Show seasons.
- Explored content additions by year and month.

### 4. Statistical Analysis

Calculated descriptive statistics, including:

- Mean
- Median
- Mode
- Minimum and Maximum
- Range
- Standard Deviation
- Variance

### 5. Data Visualization

Created the following ten visualizations:

1. Histogram
2. Bar Chart
3. Pie Chart
4. Scatter Plot
5. Line Chart
6. Box Plot
7. Correlation Heatmap
8. Count Plot
9. Pair Plot
10. Violin Plot

## Key Findings

- Total titles: 8,807
- Movies: 6,131 (69.62%)
- TV Shows: 2,676 (30.38%)
- Most common release year: 2018
- Most common content rating: TV-MA
- Top country entry: United States
- Most frequent genre entry: International Movies
- Average movie duration: 99.56 minutes
- Average TV Show duration: 1.76 seasons
- Highest content additions: 2019 (2,016 titles)
